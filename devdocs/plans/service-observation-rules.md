# 서비스별 파일 쓰기 및 TCP 연결 탐지

## 목적과 범위

Tetragon의 기존 파일·TCP 관측을 해당 서비스의 운영 기준과 비교해, 한 관측에 한 개의 탐지 전용 경보를 기록한다. 기본 구성은 빈 범위다. 기존 관측 스트림, 보존 정책과 전송 포맷을 사용한다.

## 정책과 실행 경로

호스트 YAML의 `service_observations`에서 서비스별 보호 경로, 쓰기 예외 및 허용 TCP 목적지(CIDR와 포트)를 정의한다. 현재 적용된 `detection.web_services`에 같은 서비스 이름이 명시되고 전체 탐지가 켜져야 활성화된다. 중앙 서명 정책 적용 시 서비스 범위는 서명된 웹 서비스 목록에서 가져오며 세부 경로와 목적지는 호스트 파일에서 가져온다. 서비스 이름은 해당 관측의 프로세스에 귀속된 값을 정확히 비교한다. 조상의 실행 파일명만 일치하는 이벤트에는 이 규칙을 적용하지 않는다.

- 파일 경보에는 고정 정책의 `vfs_write` 성공, 양수 반환값, 정규 절대 경로가 필요하다. 디렉터리 구성 요소 경계로 비교하고 허용 경로는 우선 제외한다.
- TCP 경보에는 고정 IPv4/IPv6 훅의 0 반환값, 목적지 주소와 포트가 필요하다. 해당 서비스의 명시적 허용 목록에 주소와 포트가 함께 맞으면 정상이다. 포트를 생략하면 해당 CIDR의 모든 포트를 허용한다. 연결 성립과 전송 내용은 이 센서의 근거 범위 밖이다.
- 누락·잘림·마스킹으로 핵심 근거가 불완전하거나 실패·결과 미상인 작업은 경보를 생성하지 않는다. 경보는 원래 이벤트와 같은 트랜잭션에서 저장하고 같은 전송 묶음에 담는다. 대응 모드와 관계없이 자동 종료는 수행하지 않는다.
- 초기 가중치는 보호 경로 쓰기 70점(높음), 목록 밖 TCP 시작 55점(중간)이다. 서비스 귀속의 계보 품질은 별도의 신뢰도에 반영한다. 소스에서 경로와 주소만으로 침해 확률을 추정하지 않는다.
- 로컬에 같은 이벤트가 보존된 동안 재수신하면 최초 판정과 전송 묶음을 유지한다. 감지 규칙을 바꿔 과거 자료를 평가하는 작업은 기존 `sentinel rules compare`로 분리한다. 본문 만료 후 로컬에서 과거 원본을 다시 주입하면 새 입력이 될 수 있다. 중앙에서 원래 묶음과 달라진 재전송은 충돌로 거절될 수 있다.
- 커널 훅·구독 범위는 기존 센서 설정을 따른다. 이 규칙을 활성화하는 작업 자체는 센서를 설치하거나 관측 입력을 늘리지 않는다. 실행 시 서비스 사전 조회와 명시적 범위 비교만 추가하고 경로 탐색·DB 조회·DNS 조회·패킷 캡처를 추가하지 않는다.

## 검증

실제 Tetragon JSON 형태로 변환·서비스 귀속·필터·엔진·로컬 저장·전송 묶음을 통과시킨다. 정상 업로드 및 접두사가 비슷한 형제 경로, 실패 쓰기, 허용 목적지·포트 일치, 잘못된 주소·포트 및 IPv6, 스풀 재전송, 다른 서비스와 정책 리비전 변경을 확인한다. 실제 서비스별 경보량은 현장 범위와 센서 수신 상태에 따라 달라진다.

## 개발본 시험 결과

- Tetragon 어댑터부터 수신한 8개 표본에서 파일과 TCP 경보가 각각 한 건 발생했다. 같은 입력을 재전송한 뒤에도 전송 묶음 수가 유지됐고, ACK 뒤 1시간 기준으로 일반 관측 6건을 만료시켰을 때 두 경보의 증거를 다시 조회할 수 있었다.
- 호스트 목록과 서명된 웹 서비스의 교집합을 정책 리비전 1–4에서 시험했다. 서비스 제거·전체 탐지 중지·재활성화가 적용됐고 로컬에 남은 같은 원본은 최초 판정을 유지했다.
- 운영에 설치된 센트럴 RPM 16 바이너리를 임시 DB와 루프백 포트에서 구동했다. 독립된 두 에이전트가 각각 두 경보를 mTLS로 전송했다. 중앙 운영자 API에서 서비스, 규칙 ID, 경로·쓰기 바이트 또는 목적지·포트, 탐지 전용 판정을 확인했다.
- [예제 설정](../../configs/examples/agent-service-observations.yaml)과 [예제 JSONL](../../testdata/events/service-observations.jsonl)로 오프라인 정책 비교를 실행하면 일반 관측 6건에서 각 규칙의 추가 경보가 한 건씩이다.
