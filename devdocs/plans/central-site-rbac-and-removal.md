# 센트럴 사이트 권한과 원격 제거

## 동작 범위

- 사이트는 권한의 범위다. 에이전트의 현재 등록은 하나의 사이트에 속한다. 그룹은 사이트 안에서 여러 서버를 선택하는 데 쓰며 한 서버가 여러 그룹에 속할 수 있다. 기존 등록은 기본 사이트에서 시작한다.
- 계정은 여러 역할을 가질 수 있고, 각 역할에는 모든 사이트 또는 한 사이트를 지정한다. 역할에는 조회, 그룹, 정책, 업데이트, 등록, 원격 제거 등 필요한 권한만 추가한다. 센트럴 자체 운영과 권한 관리는 전역 권한을 요구한다. 기존 역할은 호환을 위한 기본 역할로 제공한다.
- 브라우저에서 선택한 사이트는 조회와 요청의 범위를 지정한다. API는 계정 권한과 저장된 에이전트·그룹·사이트의 소속을 대조한다. 대상 사이트 밖의 기록, 집계와 작업 상태는 반환하지 않는다.

## 원격 제거

- 이 계약을 지원하는 관리형 RPM은 별도 설정이 없으면 원격 제거 요청을 확인한다. 호스트의 명시적 차단과 제거 금지 정책은 계속 적용된다.
- 제거 권한을 부여받은 사용자는 사이트 안에서 개별 대상, 그룹 또는 사이트 전체를 선택한다. 미사용 대상은 사용자가 선택하거나 그룹으로 지정한다.
- 미리보기에서 현재 등록별 가능 여부와 사유를 표시한다. 확인 시 정확한 대상 집합과 등록·소속을 재검증하고 확정된 대상마다 서명 요청을 발행한다. 감사에는 요청자, 사이트, 등록, 작업 상태를 기록한다.
- 에이전트는 현재 등록의 mTLS와 고정 서명 키를 확인한다. 정상 RPM 제거 직전에 센트럴로 돌아가 요청의 유효 기간, 대상 등록과 사이트, 요청 계정의 현재 권한 및 정책을 다시 확인받는다. 일회용 기존 제거 승인, 감사 전달 확인과 로컬 패키지 작업 잠금을 적용한다.
- 패키지 부재 확인이 접수된 등록만 인증서를 폐기한다. 부분 성공과 결과 미확인은 대상별 상태로 표시한다.

## 검증

서로 다른 두 사이트와 사이트별 역할을 가진 계정을 사용해 목록·직접 ID·배치 및 실행 범위를 비교한다. 기존 계정과 기본 사이트 마이그레이션, 권한 회수와 사이트 이동 후 대기 작업, 미리보기 이후 대상 변경, 업데이트 경합을 시험한다. 정상 경로는 일회용 승인과 감사 확인부터 모의 RPM 결과까지 실행한다.
